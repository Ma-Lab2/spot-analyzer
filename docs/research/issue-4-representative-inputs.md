## 1. 盘点范围与判定规则

### 1.1 输入图像与显示图像分开

盘点将能直接作为测量输入的图像定义为：

- 单通道 `L`（8 位灰度）PNG；
- 保留原始像素值、尺寸、文件名和 SHA-256；
- 不把 `out/*_raw.png`、`out/*_median.png`、`_verify_out/**` 的渲染结果重新当作输入图像。

RGB PNG、带 Matplotlib 元数据的 RGBA 输出以及便携版内部资源只作为显示图像或软件资源登记，不进入灰度测量回归集。`L` 模式和 `max=255` 只能证明编码样本达到最大码值；没有探测器线性度、满阱或曝光记录时，不把它单独解释为物理饱和。

## 3. 覆盖性结论

当前灰度输入集能可靠支持的测试是：

1. 8 位单通道解码、尺寸和范围保持；
2. 空白帧拒绝/不可用状态；
3. 弱单峰、重复帧和背景估计敏感性；
4. 达到最大码值时的饱和候选诊断；
5. 疑似亮坏点、背景纹理和边缘信号的质量门禁。

当前灰度输入集**不能提供具有解析真值的**椭圆、可控旁瓣、多峰、已知背景梯度、精确坏点位置、精确饱和阈值和可控裁边。RGB 文件也不能通过自动转灰度来填补这一缺口：转换矩阵、色彩管理和显示拉伸会改变输入强度语义。因此以下合成场景是验收必需品，而不是可选的演示数据。

## 4. 合成验证场景

### 4.1 共同约定

每个场景应生成两份文件：

- **参考数组**：浮点 `校正强度图`，保留未量化的解析值和参数；用于计算 oracle。
- **测试输入图像**：按指定位深、背景、噪声和裁剪规则编码；用于测试真实解码与质量门禁。

建议默认网格为 256×256，像元间距 `p = 0.1 µm/px`，中心使用像元坐标 `(127.5, 127.5)`，除非场景专门测试亚像元中心。每个输出都记录：

- 场景名、随机种子、数组尺寸和像元间距；
- 解析模型及全部参数；
- 量化位深、背景、噪声和饱和码值；
- 生成前后数组哈希；
- 预期状态（`ok`、`limited` 或 `unavailable`）及质量标志。

生成器不得把原始实测图像覆盖或写回外部样例目录。

### 4.2 场景表

| ID | 场景与参数 | 解析答案/可控预期 | 覆盖目标 |
|---|---|---|---|
| `gaussian_circular` | `I=A exp(-2r²/w²)+B`；例如 `A=200`, `B=10`, `w=20 px`，无噪声、无裁剪 | `FWHM=w√(2 ln 2)`；`EE(R)=1-exp(-2R²/w²)`；`EE(FWHM/2)=0.5`；`D4σ=2w`；中心已知 | 正常基准、FWHM、EE50/EE80、二阶矩和单位换算 |
| `gaussian_elliptical_rotated` | `I=A exp[-2(u²/wx²+v²/wy²)]+B`；例如 `wx=24 px`, `wy=12 px`, `θ=30°` | 主轴 FWHM 分别为 `wx√(2 ln 2)`、`wy√(2 ln 2)`；主轴 D4σ 分别为 `2wx`、`2wy`；角度已知；圆形 EE 用数值 oracle | 椭圆、旋转、主次轴排序、轴角和圆 EE 不应误当成一维宽度 |
| `two_gaussian_multimodal` | 两个已知高斯相加：主峰 `(x0,y0)`, 副峰偏移 `(35,0) px`，副峰振幅 `0.35A`，宽度为主峰 `0.8w` | 解析数组可直接积分；副峰位置和振幅已知；全域质心可由加权矩计算；单高斯拟合不应被视为整幅真模型 | 多峰、中心歧义、拟合残差、旁瓣候选和测量有效性与计算成功的区分 |
| `airy_sidelobe` | `I(r)= [2J₁(αr)/(αr)]²`，`r=0` 取极限 1；固定 `α`，再加已知背景 | 零点、第一环位置和径向曲线由 Bessel 函数解析定义；环候选应在预设噪声下可检出；不把它解释成实测物理 Airy 成因 | 旁瓣、环、径向 EE、非高斯残差 |
| `background_gradient` | 在圆高斯上加入 `B(x,y)=B0+bx x+by y`；例如 `B0=20`, `bx=0.05`, `by=-0.03` 码值/px | 未加噪声时背景真值已知；正确的背景输入应恢复基准指标；故意用常数背景时应产生可测偏差并保留参数记录 | 背景梯度、过扣/欠扣背景、负值比例、结果敏感性 |
| `hot_dead_pixels` | 在同一参考高斯上注入一个亮点和一个暗点，坐标、幅度和半径固定；另给坏点掩膜真值 | 未处理数组精确知道两个异常位置；DPC 只能标记/替换并记录，不能声称恢复真实观测；掩膜拟合与插值拟合结果应可比较 | 坏点、DPC 顺序、旁瓣假阳性、能量重分配 |
| `low_snr_seeded` | 圆高斯加零均值高斯噪声，固定随机种子；例如峰值 20、噪声标准差 5，另提供无噪声参考 | 单帧指标不要求等于参考值；应通过多种子重复报告偏差/重复性，且背景估计和检测门限可复现 | 低信噪比、噪声阈值、重复性和不确定性 |
| `saturated_core` | 对已知高斯执行 `clip(I, 0, 255)`，令核心出现连续 255 平台，并保存未裁剪参考 | 饱和像素位置/数量精确已知；峰值归一的 FWHM 和拟合应为 `limited` 或 `unavailable`，不能由滤波伪造；固定口径积分可保留但必须带标志 | 饱和、峰平台、质量门禁和不可用原因 |
| `cropped_edge` | 先生成完整高斯，再只保留使其一侧穿过数组边界的矩形窗口；不对窗口外填零 | 边界信号精确已知；窗口内 EE 是有限域 fraction，不是全束 EE；应输出 `window_truncated`，并把二阶矩/EE80标为 limited 或下限 | 裁边、分析区域、边界检查和分母语义 |

### 4.3 合成场景的验收断言

对无噪声、无量化、无裁边的 `gaussian_circular`，允许误差只来自像元积分/采样，并至少断言：

- 读回的 dtype、范围、尺寸和像元间距与 manifest 一致；
- 中心误差不超过一个采样步；
- FWHM 与解析值的误差写明是像元采样误差，不用“计算成功”代替测量有效性；
- `EE(FWHM/2)` 接近 0.5，且固定参考半径与测得 FWHM 半径使用不同字段；
- `D4σ ≈ 2w`，主次轴顺序和单位正确。

对扰动场景，断言应验证**诊断和状态**而非强求单一数值：

- 梯度、坏点、饱和和裁边均出现在结果元数据；
- 负值、掩膜计数、背景参数和随机种子可追溯；
- 多峰/环的计算可成功不等于测量有效；
- 显示图像的色图、拉伸和插值不会改变校正强度图指标。

## 5. 标定来源与限制

### 已记录来源

- 外部项目 `D:\Files\CLAPA2\Spot\CONTEXT.md`：声明默认物方像元标定为 0.42 µm/px；这是工程默认，不是本仓库验证过的校准证书。

- 本文的 PNG 模式、尺寸、最大码值和哈希来自 2026-09-08 对外部目录的直接读取。

### 未知项

- 相机型号、满阱码值、线性区、曝光、增益、响应曲线和物理饱和码值；
- 暗场/平场、坏像素表、背景帧及其采集条件；
- 0.42 µm/px 是否适用于每一个日期、倍率和物方位置；
- RGB 图像的色彩空间、转换矩阵和显示拉伸；
- 灰度图是否已经历相机内部压缩、阈值、gamma 或其他预处理；
- 单幅图像中亮点、环、纹理的物理成因。

因此：输入图像可以验证解码与流程可追溯性，但不能单独证明绝对功率、物理饱和、衍射成因、波前质量或真实 Strehl。缺少标定时应报告码值/像素单位和质量限制；不要把显示图像称为校正强度图，也不要把计算成功称为测量有效性。

## 7. 一手来源与复核边界

### 7.1 一手来源
