# Issue #5 可丢弃交互原型

这是一个不进入生产代码的单文件 UI 原型，用来验证 Spot Analyzer Windows 工作区的信息架构和视觉方向。当前评审版参考 EasyCLIProxyAPI 日间模式：淡绿色工作区背景、白色文字面板、深色文字；图像查看框只在原图黑色区域保留黑色，其余界面使用白底。

## 打开

直接双击 `spot-analyzer-workspace.html`，不需要安装依赖或启动服务。

左侧小栏现在有两个页面，底部浮动栏还有三个结构变体（地址参数为 `?variant=A` / `?variant=B` / `?variant=C`）：

- **A · 清爽三栏工作台**：左侧参数、中央图像与下方剖面图、右侧结果，适合快速连续分析。
- **B · 证据审阅**：最近输入队列 + 中央证据查看 + 右侧质量门禁，适合逐张复核。
- **C · 引导流程**：把输入、标定、分析、有效性和导出拆成五步，适合首次使用。
- **绘图模式**：论文图预设；调整色板、线宽、图例、网格和色标，预览 PNG / SVG 出图效果。

底部浮动栏的左右箭头或键盘 `←` / `→` 切换三个变体；键盘 `1` / `2` 切换分析模式和绘图模式。

## 建议评审路径

1. 在左侧小栏切换 **分析模式 / 绘图模式**。
2. 在底部浮动栏切换 A / B / C，比较信息层级、主操作和复核密度。
3. 分析模式中确认：图像黑底方框内只有图像和测量线，所有文字、图例和功能选择都在图像外。
4. 在图像上方切换 **输入图像 / 校正强度图 / 模型 / 残差**，再切换 **灰度 / 伪彩**。
5. 在图像工具栏选择 **分位数 1–99% / 全范围 Min–Max / 固定范围**，确认伪彩只改变显示，不改变测量数据。
6. 点击 **分析区域** 后再点击中央图像，确认 ROI 显示/隐藏是否符合预期；切换覆盖层，确认所有测量线和图例一起隐藏。
7. 在 A 中点击左侧 **确认空间标定** 后再自动分析；在 C 中点击 **确认并自动分析**；B 用右侧证据面板审阅标定来源。随后用右上角 **预览状态** 依次检查正常、警告、无效、空白、错误五类状态。
8. 点击 **打开 PNG** 选择本地图片，观察文件信息变为“等待分析”，再按当前变体的主操作分析；在 A 中调整高级参数并重算，在 C 中观察五步条推进。
9. 绘图模式中切换论文、打印、汇报预设，并调整色板、线宽、坐标图例、网格和色标。

原型中的图像、数值和导出均为内存中的演示数据；“导出”只显示反馈，不会写入磁盘。
